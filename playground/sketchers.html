2D sketcher bench

Run it with the dev server. In the repo: npm run dev, then open http://localhost:5173/valence/playground/sketchers.html. Opening this file straight from disk cannot work — the page's script is TypeScript, JSME is served from the dev server's /valence/jsme/ route, and OpenChemLib is an ES module (blocked over file://). Only Ketcher's iframe has a plain relative path, so it is the one panel that appears when the file is opened directly.

Dev-only, never built into the app. Three sketchers at the app's real panel size (400 × 443), each fed the same Kekulé benzene, each asked for a molfile back — so the bond orders that come out are directly comparable. Vendor assets are gitignored: unzip ketcher-standalone-3.18.0.zip (epam/ketcher releases) into playground/vendor/ketcher/, and copy dist/openchemlib.js + dist/openchemlib.d.ts + dist/resources.json from the openchemlib npm package to playground/vendor/ocl/.
